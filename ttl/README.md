# 极简版：一个 .ttl 文件

不需要 PowerShell，不需要 .NET，不需要任何编译产物。装完官方 Tera Term 5.x 之后，
`.ttl` 文件双击就由 `ttpmacro.exe` 执行。

## 用法

1. 复制 `example.ttl`，改名成自己认得的名字，比如 `web1.ttl`。
2. 改开头「改这里」的四行：主机、端口、用户名、提示符。
3. 把下面「自定义命令」那段换成自己的命令，一条命令两行：

   ```
   wait PROMPT
   sendln 'cd /var/log'
   ```

4. 双击运行。弹窗输入密码，之后自动登录并依次执行命令，终端保持打开。

一台主机一个文件。想连哪台就双击哪个，可以把它们放桌面或者钉到任务栏。

## 取舍

- **密码每次输入，不保存。** 因此没有任何加密存储的问题，也是这三种做法里最安全的。
  代价是每次都要敲一遍。
- 想保存密码的话，Tera Term 自带 `getpassword`，但它的加密**不绑定机器和账户**，
  文件被拷走就能解密。不建议用在真实服务器上。要保存密码请用上一级目录的 `ps/` 版本，
  那边用的是 Windows DPAPI，绑定当前账户。
- 密码含英文双引号时这个模板不适用（参数拼接没做转义处理）。
- 没有连接列表、没有搜索、没有分组。要这些就用 `ps/` 版本。

## 未验证

**这个模板没有在真实 Tera Term 上跑过。** 以下几处依据 Tera Term 宏文档编写，需要实测：

- `wait PROMPT` 对字符串变量求值。如果报错，把它改成字面量，例如 `wait '$'`。
- `passwordbox` 的结果放进 `inputstr`。
- `connect '/DS'` + `testlink` 建链后，`connect COMMAND` 走 DDE 而不是启动新进程。
  **这一条最重要** —— 如果它实际是启动了新进程，密码就会出现在进程命令行里，
  那就必须改用 `ps/` 版本。可以在登录时打开任务管理器的「命令行」列确认一次。
